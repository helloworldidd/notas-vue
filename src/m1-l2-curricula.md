## 1. Currícula


### 1.1. Qué aprenderemos en el curso

El curso está diseñado para desarrollar las habilidades necesarias para **construir y mantener aplicaciones o sitios web** utilizando tecnologías fundamentales del desarrollo Front-End.   

Las tecnologías principales que se aprenderán son:

Un desarrollador Front-End se especializa en **crear la parte visual de aplicaciones o sitios web**, implementando las funcionalidades que interactúan directamente con el usuario.   



### 1.2. Competencia general del curso

El objetivo del curso es:

> **Desarrollar aplicaciones web desde el lado del cliente**, aplicando buenas prácticas de la industria para resolver necesidades de organizaciones y crear productos digitales de calidad.   



### 1.3. Campo laboral

Un desarrollador Front-End puede trabajar en organizaciones de distintos sectores, por ejemplo:

* empresas de tecnología
* banca
* retail
* salud
* minería
* servicios
* instituciones públicas

Prácticamente **todas las industrias utilizan software**, por lo que requieren profesionales de desarrollo web.   



## 2. Metodología del curso

El curso utiliza una metodología **E-learning**, combinando clases en vivo con trabajo autónomo.

### 2.1. Clases sincrónicas

Clases virtuales en vivo mediante plataforma.

Duración diaria: **3 horas**

- Horarios posibles:
    - 15:00 – 18:00
    - 19:00 – 22:00

- Durante estas clases:
    * el docente explica contenidos
    * se desarrollan ejercicios
    * se resuelven dudas.   



### 2.2. Trabajo asincrónico

Además de las clases en vivo, el estudiante debe:

* revisar contenidos en la plataforma
* estudiar material complementario
* realizar ejercicios prácticos

El estudiante es responsable de **gestionar su propio aprendizaje**.   



### 2.3. Materiales y herramientas del curso

Durante el curso se utilizan distintos recursos educativos:

- **Videos educativos**: Material audiovisual que explica conceptos de cada módulo.
- **Contenidos interactivos**: Presentaciones, juegos, cuestionarios y actividades interactivas.
- **Quiz**: Evaluaciones breves para reforzar el aprendizaje.
- **Trabajos prácticos**: Actividades donde los estudiantes aplican lo aprendido:
    * trabajos individuales
    * trabajos grupales.   



## 3. Estructura del curso

El curso está dividido en **9 módulos**, cada uno con competencias y actividades prácticas.   



### 3.1. Módulo 1 - Orientación al perfil

En este módulo se aprende:

* el perfil profesional del desarrollador Front-End
* el contexto de la industria TI
* la metodología del curso
* el trabajo en equipo y ética profesional.   



### 3.2. Módulo 2 - Fundamentos de desarrollo Front-End

Se estudian las bases del desarrollo web:

* HTML5
* CSS
* JavaScript
* Bootstrap
* jQuery
* GitHub

Se aprende a crear **sitios web responsivos básicos**.   



### 3.3. Módulo 3 - Desarrollo de interfaz web

Se trabaja en el diseño y estructura visual de las interfaces.

Se aprenden conceptos como:

* organización de estilos
* metodologías de CSS
* preprocesadores
* modelo de cajas
* Bootstrap para layouts y componentes. 0}  



### 3.4.  Módulo 4 - Fundamentos de JavaScript

Se introducen los conceptos básicos de programación:

* variables
* condicionales
* arreglos
* ciclos
* funciones
* objetos. 1}  



### 3.5.  Módulo 5 - JavaScript avanzado

Se profundiza en programación JavaScript:

* programación orientada a objetos
* eventos
* programación asíncrona
* manipulación del DOM
* consumo de APIs
* uso de Fetch y XHR. 2}  



### 3.6.  Módulo 6 - Interfaces con Vue

Se aprende a construir interfaces modernas utilizando **Vue.js**.

Contenidos principales:

* framework basado en componentes
* templates
* form binding
* manejo de eventos
* navegación con Vue Router. 3}  



### 3.7.  Módulo 7 - Aplicaciones con Vue

Se desarrolla una aplicación completa usando Vue.

Se trabaja en:

* componentes reutilizables
* consumo de APIs REST
* manejo de estado con Vuex
* pruebas unitarias. 4}  



### 3.8.  Módulo 8 - Portafolio digital

Los estudiantes desarrollan un **producto digital real** y lo integran en un portafolio profesional.

El portafolio permite:

* mostrar habilidades técnicas
* demostrar proyectos realizados
* mejorar oportunidades laborales. 5}  



### 3.9.  Módulo 9 - Empleabilidad

En este módulo se aprende a prepararse para el mercado laboral.

Se trabaja en:

* plan de búsqueda de empleo
* creación de CV tecnológico
* preparación para entrevistas
* comprensión del mercado TI. 6}  



## 4. Portafolio

### 4.1. Qué es un portafolio de producto

Un **portafolio** es una colección de proyectos que demuestra:

* habilidades
* conocimientos
* experiencia

Permite mostrar evidencias concretas del trabajo realizado durante el aprendizaje. 7}  



### 4.2. Importancia del portafolio

Un portafolio permite:

* demostrar lo que sabes hacer
* mostrar calidad de trabajo
* facilitar la búsqueda de empleo
* destacar frente a otros candidatos. 8}  



### 4.3. Cómo se construye el portafolio

Durante el curso:

* cada módulo incluye una actividad práctica
* los proyectos se suben a **GitHub**
* los trabajos forman parte del portafolio final

Al final del curso el estudiante tendrá un conjunto de proyectos que podrá presentar a futuros empleadores. 9}
